## 🎨 Customization

### Change Offerings
Edit the pricing table in `index.html` to modify packages or prices.

### Change Email
Update the email address in `script.js`:
```javascript
const CONTACT_EMAIL = 'your-email@domain.com';
```

### Update Colors
Edit CSS variables in `style.css`:
```css
:root {
    --primary-color: #d4af37;      /* Gold */
    --secondary-color: #8b4513;    /* Brown */
}
```
